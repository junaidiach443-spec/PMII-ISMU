Cara Menghubungkan ke Database MySQL (XAMPP / cPanel):

  1. Buka XAMPP Control Panel dan klik Start pada modul Apache dan MySQL.
  2. Buka browser dan akses http://localhost/phpmyadmin.
  3. Buat database baru dengan nama `db_pmii_ismu`.
  4. Klik tab Import, pilih file `database.sql` dari folder proyek ini, lalu klik Go / Impor.
  5. Pindahkan folder proyek ini ke dalam folder `htdocs` XAMPP (contoh: C:/xampp/htdocs/app-pmii-ismu/).
  6. Buka aplikasi lewat alamat http://localhost/app-pmii-ismu/. Sistem otomatis mendeteksi database MySQL!
